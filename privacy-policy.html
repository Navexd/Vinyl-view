Politique de confidentialité

Vinyl View — Dernière mise à jour : mars 2026

Vinyl View est une application desktop locale. Elle n'utilise aucun serveur externe et ne transmet aucune donnée personnelle à des tiers.

1. Qui sommes-nous

Vinyl View est développée par Navexd, à titre personnel. Contact : votre@email.com

2. Données collectées

Vinyl View collecte uniquement les données strictement nécessaires à son fonctionnement :

  • Token d'authentification Spotify — généré lors de la connexion OAuth, stocké localement sur votre appareil uniquement.
  • Données de lecture en cours — titre, artiste, album et pochette du morceau en cours de lecture sur Spotify. Ces données sont affichées localement et jamais transmises.

3. Comment les données sont utilisées

Les données récupérées via l'API Spotify sont utilisées exclusivement pour :

  • Afficher le morceau en cours de lecture dans l'interface de l'application
  • Animer le tourne-disque virtuel en fonction de l'état de lecture

Aucune donnée n'est analysée, vendue, partagée ou transmise à un serveur externe.

4. Stockage des données

Le token OAuth Spotify est stocké localement dans :

  • Linux / macOS : ~/.config/vinyl-view/token.json
  • Windows : %APPDATA%\vinyl-view\token.json

Ce fichier reste sur votre appareil et n'est jamais transmis.

5. Communication réseau

Vinyl View effectue uniquement les communications suivantes :

  • API Spotify (api.spotify.com) — pour récupérer les informations du morceau en cours
  • OAuth Spotify (accounts.spotify.com) — pour l'authentification initiale
  • Localhost (127.0.0.1:3000) — communication interne entre le backend et l'interface de l'app

Aucune autre communication réseau n'est établie.

6. Scopes Spotify utilisés

  • user-read-currently-playing — lire le morceau en cours de lecture
  • user-read-playback-state — lire l'état de lecture (play/pause, contexte)

Ces scopes sont les plus restrictifs possible pour le fonctionnement de l'application.

7. Suppression des données

Pour supprimer toutes les données stockées par Vinyl View :

  • Supprimez le dossier ~/.config/vinyl-view/ (Linux) ou %APPDATA%\vinyl-view\ (Windows)
  • Révoquez l'accès de Vinyl View depuis votre compte Spotify

8. Mineurs

Vinyl View ne collecte aucune donnée personnelle et ne cible pas spécifiquement les mineurs.
